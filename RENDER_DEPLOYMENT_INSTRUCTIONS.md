# 🚀 Render Deployment Instructions

## What Was Fixed

### 1. ✅ LEAN Engine Import Issue
- Added `start.sh` script that sets `PYTHONPATH` before starting the server
- Updated `Dockerfile` to include `/app/backend` in `PYTHONPATH`
- Ensures `lean_engine` module can be imported on Render

### 2. ✅ BigQuery Dependency Removed
- `BacktestOrchestrator` now uses PostgreSQL database directly
- No longer requires Google Cloud credentials
- Uses SQLAlchemy to query holdings and filings tables

### 3. ✅ Real API Calls Enabled
- Backtests now use `BacktestOrchestrator` with real data when LEAN unavailable
- Fetches data from AlphaVantage API (market data)
- Fetches data from SEC EDGAR API and PostgreSQL database (filings)
- Shows real-time progress during data fetching

## Deploy Steps

### Option A: Automatic (Recommended)
1. Push to GitHub:
   ```bash
   git push origin main
   ```

2. Render will auto-deploy (takes ~3-5 minutes)

3. **No manual steps needed!** ✅

### Option B: Manual Configuration (If Option A doesn't work)

If Render doesn't detect the changes, update the start command manually:

1. Go to Render Dashboard → Your Service → Settings
2. Update **Start Command** to:
   ```bash
   cd backend && bash start.sh
   ```
3. Save and Render will redeploy

## Environment Variables on Render

Make sure these are set in Render dashboard:

**Required:**
- `DATABASE_URL` - PostgreSQL connection string (auto-set by Render)
- `ALPHAVANTAGE_API_KEY` - Your AlphaVantage API key

**Optional:**
- `JWT_SECRET_KEY` - Auto-generated by Render
- `CORS_ORIGINS` - Set to `https://pathvest.vercel.app`

## Troubleshooting

### If you still see "LEAN engine not available"
Check the logs for import errors. If you see:
```
ModuleNotFoundError: No module named 'lean_engine'
```

Then PYTHONPATH isn't set correctly. Make sure:
1. `start.sh` is executable: `chmod +x backend/start.sh`
2. Start command uses `bash start.sh` (not `uvicorn` directly)

### If you see "No institutions selected"
This means the frontend isn't sending institution selections. Check:
1. Frontend deployed to Vercel with latest code
2. localStorage shows `strategyConfig` with `selected_institutions`
